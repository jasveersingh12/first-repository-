# 📊 Sales Data Analysis Project

This repository contains a comprehensive sales data analysis project using **Power BI** and **SQL**. The project demonstrates data modeling, business insights generation, and solving real-world analytics queries using structured datasets.

## 📁 Dataset Overview

The analysis is based on three interconnected tables:

### 1. `Sales`

Captures transactional-level sales data including customer, product, and performance details.
**Columns:**

* `Date`
* `Customer Type`
* `Country`
* `Product`
* `Discount Band`
* `Units Sold`

### 2. `Discount`

Defines discount rates applicable based on time period and discount category.
**Columns:**

* `Month`
* `Discount Band`
* `Discount`

### 3. `Product Details`

Contains product metadata used to enrich sales analysis.
**Columns:**

* `Product ID`
* `Product`
* `Category`
* `Cost Price`
* `Sale Price`
* `Brand`
* `Description`

---

## 🎯 Key Objectives

* Perform dynamic visual analysis using Power BI dashboards.
* Solve practical SQL questions related to sales performance, customer segmentation, and discount insights.
* Join and transform data for meaningful reporting.

---

## 🛠️ Tools Used

* **Power BI** for data modeling and visualization
* **SQL** for querying, filtering, aggregating, and joining datasets
* **Excel/CSV** (initial format of data files)

---

## ✅ Highlights

* Built **interactive Power BI dashboards** to explore sales trends by customer type, country, and product categories.
* Answered key business questions such as:

  * What is the total revenue by country and discount band?
  * Which brands perform best across different regions?
  * What is the impact of discount levels on units sold?
